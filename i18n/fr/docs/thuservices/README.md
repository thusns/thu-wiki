## Vous savez quelque chose d’important mais il n’est pas répertorié dans le dépôt ?

Les contributions sont les bienvenues ! S'il vous plaît [PR](https://github.com/ZenithalHourlyRate/thuservices/pulls) !

Il convient de noter que [pre-commit hook](https://github.com/ZenithalHourlyRate/thuservices/blob/master/pre-commit) est utilisé dans [本 repo](https://github.com/ZenithalHourlyRate/thuservices), veuillez [安装](https://git-scm.com/book/zh/v2/%E8%87%AA%E5%AE%9A%E4%B9%89-Git-Git-%E9%92%A9%E5%AD%90), et validez dans un environnement avec bash et python3.

Sous l'action du hook de pré-commit, README.md est automatiquement généré, donc si vous devez le modifier dans README.md, veuillez le faire sous [aux 文件夹](https://github.com/ZenithalHourlyRate/thuservices/tree/master/aux).

En raison des limitations du système de fichiers Windows, le nom du dossier ne peut pas être aux. Veuillez cloner le projet dans un environnement non Windows (WSL est également disponible).

### compiler

```
python3 -m pip install --user -r requirements.txt # 安装 Python 依赖包
mkdocs serve # 直接在本地 serve，或者：
mkdocs build --clean # 生成于 site/ 文件夹中
```
