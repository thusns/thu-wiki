# военная подготовка

### военные навыки

1. **Встаньте по стойке смирно, отдохните, повернитесь, присядьте, присядьте, встаньте, идите в ногу, идите в ногу**
   (Повороты при беге и движении не исследовались)
2. **Военный бокс**
3. **Раздельный шаг** (то есть перед трибуной Дунцао он меняется с марша на гусиный шаг, а затем на марш в тандеме)
4. **Отчетность**: военный бокс, учения по убийствам, учения по языку флага, учения с кинжалом (каждый батальон выбирает одно из упражнений)
5. **Стрельба** (в последние годы не боевыми патронами)
6. **Практика** (20 километров)

Оценка: 3,6 за большинство, 4,0 за выдающуюся производительность.
