# Инструменты Амвей

## Как получить электронные книги

1. Платформа обучения женьшеню: http://reserves.lib.tsinghua.edu.cn/，内含许多教材，如没找到还可以向图书馆请求教材。
2. Z-библиотека (требуется магический доступ в Интернет)
3. Справочный союз национальных библиотек http://www.ucdrs.superlib.net/
4. Поиск книг Jiumo https://www.jiumodiary.com/
5. PDF-диск https://www.pdfdrive.com/
6. Лорфри https://ebook2.lorefree.com/
7. Поиск книг на Таобао стоит около 2-3 юаней/книга.
