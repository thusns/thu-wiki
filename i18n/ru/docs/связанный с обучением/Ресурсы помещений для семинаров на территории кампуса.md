# Ресурсы помещений для семинаров на территории кампуса

Следующие помещения для семинаров можно зарезервировать в официальном аккаунте домашней сети Tsinghua; при использовании вам необходимо иметь при себе студенческий билет на три человека и сменить ключ в офисе администратора учебного корпуса:
* Помещение для семинаров Академии Цинхуа: имеется 4 зала для семинаров на 6-8 мест.
* Четыре зала для семинаров: 12 залов для семинаров на 6–10 мест.
* Шесть залов для семинаров: есть 3 6-местных зала для семинаров.
* Подземный зал для семинаров Фату: есть 2 6-местных зала для семинаров.

В Student Tsinghua можно зарезервировать следующие помещения для семинаров (веб-сайт, официальный аккаунт, мини-программа):
* 2-й этаж корпуса C: три зала для семинаров на 10 человек и 4 зала для семинаров на 20 человек.
* Третий этаж корпуса C: 6 небольших залов для семинаров (2 человека), 4 зала для семинаров среднего размера (11 человек) и 2 больших зала для семинаров (около 30 человек);
* Подземелье Южной зоны: здесь есть 12 исследовательских комнат вместимостью от 10 до 200 человек.
