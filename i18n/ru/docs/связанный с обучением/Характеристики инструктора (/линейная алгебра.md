# линейная алгебра
#### Лян Синь
1. **Умеренный темп**, один урок обычно состоит из одной главы (введение в линейную алгебру является учебником)
2. **Веселый и юморной, активный в классе** (помогает ученикам отвечать на их вопросы)
3. **Много домашнего задания**, утверждается, что нужно задавать больше вопросов, чтобы углубить понимание.
4. Ни имен, ни вопросов
