## Инструкции, связанные с системой выбора курсов

В вашей школе есть две или даже три системы отбора курсов, а именно zhjw, zhjwxk и zhjwxkyw. Последние два находятся в пределах времени выбора курса.
Включите, первый включится нормально.

В первом случае обычный путь доступа — [ACADEMIC](http://academic.tsinghua.edu.cn/) (за пределами кампуса требуется VPN).
->Войти->Колонка выбора курса слева->Выбор курса бакалавриата. Обычно используется для просмотра информации об открытии курса в часы, не связанные с выбором курса.

Победитель может войти через ярлык или войти через промежуточный интерфейс после входа в info/academic, webvpn.
Это также указывает на эту систему выбора курса 3. Этот метод входа возможен только тогда и только во время выбора курса.

Последний аналогичен среднему, вам нужно только изменить соответствующий URL во время работы.

## Электронная почта Университета Цинхуа

Адрес электронной почты студента — abbr@mails.tsinghua.edu.cn, и вы можете использовать abbr@mails.thu.edu.cn для получения электронных писем.

Адрес электронной почты учителя — abbr@mail.tsinghua.edu.cn, вы также можете использовать abbr@tsinghua.edu.cn. Оба эквивалентны.

Специальной реализации списка рассылки не существует. Обычно для реализации списка рассылки используются почтовые ящики учителей, а групповая переадресация.

Нет abbr@thu.edu.cn.

У Цинхуа также есть доменное имя tsinghua.edu. Хотя проблема была решена, она не использовалась (Примечание: ustc.edu по соседству используется в качестве адреса электронной почты выпускников)
