## Знаете что-то важное, но этого нет в репозитории?

Вклады приветствуются! Пожалуйста, [PR](https://github.com/ZenithalHourlyRate/thuservices/pulls)!

Следует отметить, что [pre-commit hook](https://github.com/ZenithalHourlyRate/thuservices/blob/master/pre-commit) используется в [本 repo](https://github.com/ZenithalHourlyRate/thuservices), пожалуйста, [安装](https://git-scm.com/book/zh/v2/%E8%87%AA%E5%AE%9A%E4%B9%89-Git-Git-%E9%92%A9%E5%AD%90) и зафиксируйте в среде с bash и python3.

Под действием перехватчика pre-commit README.md генерируется автоматически, поэтому, если вам нужно изменить его в README.md, сделайте это в [aux 文件夹](https://github.com/ZenithalHourlyRate/thuservices/tree/master/aux).

Из-за ограничений файловой системы Windows имя папки не может быть aux. Пожалуйста, клонируйте проект в среде, отличной от Windows (также доступен WSL).

### компилировать

```
python3 -m pip install --user -r requirements.txt # 安装 Python 依赖包
mkdocs serve # 直接在本地 serve，或者：
mkdocs build --clean # 生成于 site/ 文件夹中
```
