# 군사 훈련

### 군사 기술

1. **주의를 기울이고, 쉬고, 돌아서고, 앉고, 쪼그리고 앉고, 일어서고, 발걸음을 떼고, 발걸음을 떼며 걷기**
   (달리기 및 주행 중 회전은 조사하지 않음)
2. **군복싱**
3. **스플릿 스텝**(즉, 동차오 연단 앞에서 행군에서 거위걸음으로 변경한 후 2인 행진으로 변경)
4. **성과보고** : 군복싱, 암살훈련, 기어훈련, 단검훈련(각 대대별 훈련 중 1개 선택)
5. **사격**(최근에는 실탄 아님)
6. **연습**(20km)

점수: 대부분 3.6점, 뛰어난 성과 4.0점
