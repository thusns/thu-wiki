## 캠퍼스 네트워크

### 캠퍼스 네트워크 요금

학교에 공식적으로 등록된 학부 및 대학원 계정
기본 서비스: 동적 IPv4, IPv6 주소, 네트워킹 권한 5개, 이메일 주소 1개.
비용: 0위안/월. 전염병 기간 동안 50GB를 초과하는 캠퍼스 외부 IPv4 인바운드 트래픽에 대해서는 요금이 부과되지 않습니다. 즉, 무제한 무료 사용이 가능합니다.

### 케이블 네트워크

벽면에 있는 네트워크 포트에 인터넷 기기를 네트워크 케이블로 연결한 후, 브라우저를 열고 인증시스템 URL http://login.tsinghua.edu.cn을 입력하거나, 정보포탈 http://info.tsinghua.edu.cn에 접속하여 점프하세요. 이후, 캠퍼스 네트워크 인증 로그인 페이지(보라색)에서 캠퍼스 네트워크 계정과 비밀번호를 입력하신 후, "네트워크 연결"을 클릭하시면, 캠퍼스 네트워크에 성공적으로 접속하신 후 네트워크 리소스에 접속하실 수 있습니다.

### 무선 네트워크

"Tsinghua" 및 "Tsinghua-"로 시작하는 Wi-Fi는 캠퍼스 무선 네트워크입니다. 연결 후 인증 로그인 페이지(주황색)가 자동으로 팝업됩니다. http://login.tsinghua.edu.cn을 방문하거나 정보 포털 http://info.tsinghua.edu.cn에 액세스하여 이동할 수도 있습니다. 이후, 캠퍼스 네트워크 인증 로그인 페이지(보라색)에서 캠퍼스 네트워크 계정과 비밀번호를 입력하신 후, "네트워크 연결"을 클릭하시면, 캠퍼스 네트워크에 성공적으로 접속하신 후 네트워크 리소스에 접속하실 수 있습니다.
