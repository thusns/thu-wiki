# 도구 암웨이

## 전자책을 구하는 방법

1. 인삼 교육 서비스 플랫폼: http://reserves.lib.tsinghua.edu.cn/，内含许多教材，如没找到还可以向图书馆请求教材。
2. Z-라이브러리(마법의 인터넷 접속 필요)
3. 국립 도서관 참고 연합 http://www.ucdrs.superlib.net/
4. Jiumo 도서 검색 https://www.jiumodiary.com/
5. PDF 드라이브 https://www.pdfdrive.com/
6. 로어프리 https://ebook2.lorefree.com/
7. 타오바오에서 도서 검색 비용은 도서당 2~3위안 정도입니다.
