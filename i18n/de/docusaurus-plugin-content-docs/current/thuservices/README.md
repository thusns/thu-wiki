## Wissen Sie etwas Wichtiges, aber es ist nicht im Repo aufgeführt?

Beiträge willkommen! Bitte [PR](https://github.com/ZenithalHourlyRate/thuservices/pulls)!

Es ist zu beachten, dass [pre-commit hook](https://github.com/ZenithalHourlyRate/thuservices/blob/master/pre-commit) in [本 repo](https://github.com/ZenithalHourlyRate/thuservices) verwendet wird, bitte [安装](https://git-scm.com/book/zh/v2/%E8%87%AA%E5%AE%9A%E4%B9%89-Git-Git-%E9%92%A9%E5%AD%90) und in einer Umgebung mit Bash und Python3 festschreiben.

Unter der Aktion des Pre-Commit-Hooks wird README.md automatisch generiert. Wenn Sie es also in README.md ändern müssen, tun Sie dies bitte unter [aux 文件夹](https://github.com/ZenithalHourlyRate/thuservices/tree/master/aux).

Aufgrund von Einschränkungen des Windows-Dateisystems kann der Ordnername nicht „aux“ lauten. Bitte klonen Sie das Projekt in einer Nicht-Windows-Umgebung (WSL ist ebenfalls verfügbar).

### kompilieren

```
python3 -m pip install --user -r requirements.txt # 安装 Python 依赖包
mkdocs serve # 直接在本地 serve，或者：
mkdocs build --clean # 生成于 site/ 文件夹中
```
