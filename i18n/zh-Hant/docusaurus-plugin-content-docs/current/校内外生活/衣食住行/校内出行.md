# 校內出行

## 校車

* 校園公車是“招手上車，就近下車”，可以攜帶大件行李。
  * 可以使用「清華校園巴士」微信小程式監控校園車線路的發車狀況。
  * 校內人員憑清華證件免費搭乘, 校外人員搭乘2元/人次（週末、假日3元/人次）。
* 外環：平日7:20-18:00，星期六、日及法定假日8:30-17:30，寒暑假營運以公告為準
* 內環：平日上午7:40-11:10 下午12:40-17:25，星期六、日及法定假日停運，寒暑假停運
* 學生專線：平日早7:40、9:20、下午1:00、2:50，星期六、日及法定假日停運，寒暑假停運
* 送醫專線：週一、三、五發往北醫三院，週二、四發往西苑醫院，8:00校醫院發車，8:05到達老人活動中心停靠

**_詳見「清華大學官網」中的「走進清華」- 「實用資訊」 - 「校內交通」_**
