# 校內咖啡店

（待補充呀，口感，價位......）

### 清青咖啡

海淀區觀疇園南側

1. 飲品平均20-30，一餐人均50-70
2. 味道還可以，分量較大
3. 裝潢簡約高端，環境優雅安靜（雖然人氣旺），WiFi不太給力

### 拾年咖啡

新學堂路口西南角（近蒙民偉音樂廳）------營業時間：8：00-22：00

1. 價格普遍偏貴
2. 上菜速度較慢，（美式咖啡踩雷，紅絲絨與楊枝甘露種草？）
3. 歐式風格裝潢，有露台

### 安家小廚

北京大學燕東園店------營業時間：9：00-17：00

1. 價位正常水準（有偏貴的，也有實惠的反應，具體一個菠蘿包7元）
2. 菜色較多好評
3. 環境較為吵雜，人很多（QAQ有時買麵包都要排隊）

### 有理咖

芝蘭園二樓甬道盡頭（荷清路七號，清華外國留學生工作辦公室附近）；偶爾會有貓貓出現；開到凌晨，可購買刷夜套餐刷夜。

### 仰望咖啡館

李文正館內

### 獨峰書院

觀疇園正前方約60公尺處平居二樓（由露天梯上去）------營業時間：9：30-21：30（現在還開嗎？）

1. 價格較實惠，不時有秒殺活動近乎白嫖
2. 菜色普遍好評（漢堡很大）
3. 環境很棒，古舊風，有書架。有露台。 1-5人適宜。

### 清青永和

觀疇園一層（西北面）------營業時間：9：00-21：00

需要從外面進入；

1. 性價比一般，價格偏貴，一餐人均60-100，套餐較便宜
2. 味道還OK，上菜速度較慢（30min）
3. 環境比較好，一般人少，隨機觸發人潮
