# 遊樂場

### 北京環球度假區

距離：**34.8km**
開放時間：10：00-19：00（18：00最晚入場）
票價：528￥
簡介：亞洲第三座，全球第五座環球影城主題樂園，吸引無數喜愛主題樂園的年輕人打卡。
### 石景山遊樂園
距離：**14.9**
開放時間：9：00-16：30
票價：學生￥5，園區內專案另算
簡介：北京建成最早的遊樂場，裡面的摩天輪是無數人童年的回憶。
### 北京歡樂谷

距離：**21.3km**
開放時間：9：30-22：00
票價：未滿18【258￥】，身高1.5公尺以下【193￥】，成人297￥
內容簡介：適合全家出動的主題樂園，賞美景，看表演，嗨玩超多刺激有趣的遊樂項目。
