# 校醫院就醫流程

參考： https://mp.weixin.qq.com/s/P7D4jtaZHo4PHC6CvwBXmw

## 基本狀況

校醫院位於校園的最西側，接近近春路，位於醫學科學大樓南側。其門診時間為**平日8:00-11:30, 13:30-16:30；週末與假日8:00-11:30**。急診24小時開放。

## 掛號

口腔科以外的掛號可在微信公眾號「清華大學醫院」或支付寶搜尋「清華大學醫院」。從未就診過的用戶需先在“個人中心”欄中綁卡；已綁卡用戶在“醫療業務”一欄中選擇“掛號”，並選擇需要的科室進行掛號。 **同學注意在掛號資訊確認介面，請選擇「公費醫療」以透過健保報銷。 ** 掛號後可直接到對應科室的分診台進行分診，具體流程可諮詢校醫院服務台。在取藥前選擇醫療業務-繳款，並選擇「公費醫療」以透過醫療保險報銷。
口腔科的號碼非常熱門，需要每天8點在 **「清華後勤」** 公眾號中掛號。

## 轉診

若有限於校醫院技術或設備條件不能診治的疾病，由校院為同學開立轉院會診申請單，蓋章有效。通常轉往北醫三院。同學可持學生證、醫療收費票據、費用明細清單、如有藥費還需提供醫療保險專用處方底方、以及轉院會診申請單，於 **每週一至週五上午8:30-11:30，下午13:00-16:00（週四下午除外）**到校醫**北樓三層東側辦理報銷**。
