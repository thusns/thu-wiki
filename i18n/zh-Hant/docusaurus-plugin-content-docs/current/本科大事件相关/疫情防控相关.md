# 疫情防治相關

## 常態化防控措施通知範例

1\.**學生臨時出入校**。

在京已滿7天且無涉疫行程（健康寶綠碼）的同學，申請當日臨時進出校的，可提前在學校在線服務系統（TsinghuaOS）的“學生出入校審批”中選擇“當日出校且入校”或“當日入校且出校”，如實踐信息其中，因學習科研出校的需提交指導教師出具的科研證明，就醫的需提供預約掛號證明，實習/上課的需提交實習/上課證明，其他生活服務需求等事由均需在系統完整說明。出校後，須做到校園與審批目的地“兩點一線”，做好個人防護，不得前往未經審批的其他場所和本市涉疫區域。

2\.**學生離校/離京。 **

**從嚴審批學生離京申請，因極特殊情況**確需離校/離京的，須透過線上服務系統的「學生出入校審批」中選擇「僅出校」申請，**經所在院系審批同意後方可離校/離京**。

3. **學生返校/返京**。

校內住宿的學生申請返校的，如7天內無陸路邊境口岸、一例以上感染者、中高風險所在的縣（市、區、旗）旅居史，通過在線服務系統的“學生出入校審批”中選擇“僅入校”申請，**經所在院系及學校二級審批/可審/**返。在京不滿7天的，返京返校後入住校內集中住宿點，完成在京7天健康監測及核酸「7天7檢」後方可返回宿舍居住。

4.非全日制研究生暫停進校上課；因特殊情況確需進校的，如在京已滿七天且無涉疫行程（健康寶綠碼），參照第1條執行。

5.深圳國際研究生院學生的疫情防治管理相關要求，由深研院依屬地疫情防治政策另行製定。

請全體同學自覺遵守疫情防治各項規定，落實常態化核酸檢測要求，**如有相關身體不適症狀，第一時間上報並就醫，嚴格落實疫情防控個人責任。 **確需出入校的，須遵守承諾，如實、準確、完整填寫信息，做好個人健康防護，不前往酒吧等聚集性場所。對於瞞報、謊報、漏報、遲報個人疫情相關信息，或違反疫情防控管理規定並造成不良後果的，將依法依規嚴肅處理。

疫情防控，人人有責，讓我們攜手共築平安健康校園！若疫情情勢變化或上級要求有新的調整，校方將及時調整管理要求，屆時將另行通知。
