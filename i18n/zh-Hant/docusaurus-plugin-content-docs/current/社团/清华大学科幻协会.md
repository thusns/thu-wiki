# 清華大學科幻協會



【這裡是川陀，這裡是夏爾，這裡是錫安，這裡是我們的永無島

這裡，就是你的家園】

## 簡介

清華大學學生科幻協會創立於1996年初，從屬於清華大學，是國內一流的學生科幻愛好者社團，社團文化青春昂揚，追求創新，動手創作，相繼湧現出了江波、薛輝、郝景芳等眾多人才。曾獲2019年銀河獎最佳科幻團體獎，協會累計會員近800名，自創辦以來，一直鼓勵原創活動，作品散見於《科幻世界》、蝌蚪五線譜等知名科幻平台上。

## 會刊介紹

### 《E=mc^3：邊角料科研奇思錄》

### ![](https://github.com/thusns/thu-wiki/blob/main/images/auto-upload/s34265771.jpg?raw=1)

#### 簡介

即使提前知道了結果，探索的過程也沒有省去多少，到頭來，我們還是只能以我們的方式，去認知，去探索。 ——《真理的海洋》

那將是一群，勇於竊取神明的知識的盜賊，他們將成為技術家，重燃巨風之火。 ——《盜賊的奉獻》

《E=mc3：邊角料科研奇思錄》是一本關於科技工作者和科研工作的科幻小說雜誌書，以科幻小說為載體，呈現了一線研究者的日常生活狀況及其情感關懷。書名標題中涉及的公式純屬虛構，靈感源自愛因斯坦質能轉換方程式。科幻小說時常會改寫陳規慣例，藉此重新思考何為不變之真理。本書標題亦旨在喚起類似的思考。

#### 評價

書中的這些作品，或許有些青澀，卻展現了令人期待的潛力。我衷心祝福他們中有人能堅持創作，成為未來的科幻明星，也祝愿所有同學能在自己熱愛的領域裡不斷發揮自己的才智、感受創造的樂趣，希望他們在多年以後回首過往時能夠帶著愉快的心情說：“在美好的青春歲月裡，我也是一位科幻作家。” ——飛氘

《E=mc3：邊角料科研奇思錄》展現了新一代高校科幻愛好者的風采，他們將科幻文學演變成了科幻文化，並在這種文化氛圍中創造出了激情四溢的未來。 ——凌晨

### 《無名之國》

![](https://github.com/thusns/thu-wiki/blob/main/images/auto-upload/s33969218.jpg?raw=1)

#### 簡介

清華大學學生科幻協會創立於1996 年，歷經一次斷代，至今已有24年歷史。在本書中，我們將從多個角度介紹清華課外文化、社團文化，以及清華對科幻的執著，對科學興趣的熱愛。以真實的清華的課外校園文化，影響當代青少年。

《尋找旦旦》和《那些神祕的社員們》是協會內歷史最悠久的一項活動的成果：在活動中，社員會以其他社員為對象創作幻想故事，藉此增進對彼此的了解；「幻想嘉年華」一節會展覽協會原創部的成員在筆會上的即興幻想，包括一套《異星》20185 大白菜集71857575753535年；年清華北大聯合徵文活動的優秀作品，以全國兩所頂尖高校為舞台，展現了別樣的大學生日常。這將是國內第一份公諸於世的高校科幻社團史，也將影響中學同學效仿，在業餘時間追求有價值的愛好生活。

全書從「世界」和「我們」兩個角度展現科幻社群的魅力。前者講述世界科幻社群發展史上最令人興奮的若干事件，後者著眼於呈現清華大學學生科幻協會的社團風貌。節標題則全部取自經典幻想文學作品，內容順次為：微科幻速讀（《路邊野餐》）、幻迷日常（《我不屬於他們》）、科學與科幻（《太空序曲》）、奇思妙想集錦（《奇幻嘉年華》）、科幻迷的架空世界（《烏有新聞》）和協會文化（《奇幻嘉年華》）、科幻迷的架空世界（《烏有新聞》）和協會文化（《奇幻嘉年華》）。

針對世界科幻文化，本書從三方面呈現科幻社群的主要發展軌跡。 《美國科幻圈的誕生》整理了上個世紀三十年代美國科幻迷從零到一舉辦首屆世界科幻大會的來龍去脈；《技術宅的天梯》介紹了同時期以阿瑟·克拉克為首的英國科幻愛好者所製定的史上首份載人登月計劃；《微型國家漫遊指南》則講述了科幻人因千奇歷千奇歷的千奇世文化變化指南。從三篇作品中，讀者能清楚地看到科幻在文化、科技和政治經濟領域中所扮演的豐富角色。
