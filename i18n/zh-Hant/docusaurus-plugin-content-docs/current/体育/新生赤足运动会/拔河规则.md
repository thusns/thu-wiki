# 新生運動會拔河規則

## 參賽人數

每院系限報1個冠軍班隊（男16人，女2人）。只有在單位性別人數不足，可採用以下對換的方式（1）：男生不夠的班級可採用2女生替換1男生；2）一個班女生不足2人甚至沒有女生的班級，則可讓女生上場，或女生不上場，換一個男生上場）。如情況不實一經核實則取消比賽成績。

## 檢錄辦法

1. 按賽程表提早5分鐘到場報到。如開賽後5分鐘內未到場比賽，視為自動棄權。
2. 當比賽時間已到時，該院係到場人數超過12人時，即開始比賽。如少於12人，則按上條1.處理。
3. 參加比賽的學生，均需帶學生證以便核查身分。

## 比賽辦法

1. 採用單淘汰制。
2. 每場比賽三局兩勝。每局時限3分鐘，如到時仍未能決出勝負，則以標記為準。

## 參賽規定

1. 著運動裝、衣服鞋，不得攜帶其它物品。
2. 觀眾和指揮的學生不得進入比賽區的控制線內，在看台上觀看比賽。
3. 弄虛作假和違反規定的系，當場判負，並取消該系年度“馬約翰杯”體育道德風尚獎評選資格資格。

## 未盡事宜，由新生運動會競賽小組解釋。
