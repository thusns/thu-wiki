# 常用校內公眾號及小程式整合

**清華大學學生會**：清華大學學生會官方公眾號；
**清華大學小研在線**：清華大學研究生會官方公眾號；
**清華大學本科教學**：校內教育工作相關；
**清華大學國際教育**：校內國際教育相關；
**清華紫荊之聲**：共青團清華大學委員會官方公眾號；
**清華體育**：清華大學體育部官方公眾號；
**清華職業輔導**：學生職業發展中心官方公眾號；
**清華資訊化**：資訊化工作相關；
**學習清年**：有關黨的知識學習；
**學在清華**：教務處官方公眾平台；
**行在清華**：校園交通相關服務；
**食在清華**：飲食中心相關服務；
**THU寫作課程**：寫作與溝通教學中心公眾號；


---

## 校內服務
**清華家園網**：提供學生社區相關服務，包括電費繳納，衛生成績查詢，意見反饋，以及清華學堂、法圖、六教以及四教的研討間預約。  
**學生清華**：提供C樓2層、C樓3層、南區地下活動室的借用服務，以及水木匯、新生手冊的入口。  
**清華大學醫院**：校醫院公眾號，提供掛號，繳費服務。 （口腔科需在**清華後勤**公眾號上掛號；
**清華後勤**：提供掛號、報修、查詢等服務；
**清華小清心**：心理發展指導中心官方公眾號，提供心理諮商、團體輔導的預約等服務；
**清華大學圖書館**：提供圖書館座位預約，開閉館時間查詢等服務；
**清華大學新清華學堂**：提供新清華學堂與大禮堂的演出與電影的購票服務；
**清華大學藝術博物館**：提供藝術博物館的購票服務；
**清華大學科學博物館**：提供科學博物館相關的資訊與服務；

---
## 校園資訊
**艾生權**：校內學生權益相關資訊；
**清華大學學生公益**：提供校內志工服務相關資訊；
**清華大學社會實踐**：提供校內社會實踐相關資訊；
**清華大學青年科創**：提供校內科創訊息，包括興趣團隊、挑戰盃、星火班、闖世界計畫等消息；
**清華紅十字會**：清華紅會官方公眾號；包括健康講座資訊、捐血時間安排、急救訓練資訊等；
**清華課改之聲**：清華大學本科生課程諮詢委員會公眾號，收集學生對教學改革的意見；
