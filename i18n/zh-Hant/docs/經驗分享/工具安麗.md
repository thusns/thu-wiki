# 工具安麗

## 電子書取得方法

1. 教參服務平台： http://reserves.lib.tsinghua.edu.cn/，内含许多教材，如没找到还可以向图书馆请求教材。
2. Z-library（需要魔法上網）
3. 全國圖書館諮詢參考聯盟 http://www.ucdrs.superlib.net/
4. 鳩摩搜尋 https://www.jiumodiary.com/
5. PDF Drive https://www.pdfdrive.com/
6. Lorefree https://ebook2.lorefree.com/
7. 淘寶蒐書，約2-3元/本。
