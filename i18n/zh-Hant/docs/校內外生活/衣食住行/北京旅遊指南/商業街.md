# 商業街
### 南鑼鼓巷

距離：**10.3km**
開放時間：10：00-21：00
票價：小吃街啦，要啥票直接進
簡介：北京有名的小吃步行街，吸引無數年輕人去體驗老北京的胡同風情和地道的京城文化。

### 王府井步行街

距離：**12.9km**
開放時間：啊這
票價：啊這
簡介：數百年悠久歷史的著名商業步行街，高度還原老北京生活場景的沉浸式體驗空間。



### 前門大街
距離：**14.2km**
開放時間：全天開放
票價：免費
簡介：自古就是北京最有名的商業街，有多家老字號，還有各地的小吃匯集，很有老北京的味道。
### 北京簋（gui）街
距離：**11.2km**
開放時間：全天
票價：無
簡介：夜間美食聚集地，一到晚上就燈火通明，有很多知名網紅店，有很多排隊等位的人。
### 五道營胡同
距離：**9.km**
開放時間：全天
票價：免費
簡介：全長六百多米，面積不大，有美食，咖啡，酒吧，服飾等很有特色的小店。
