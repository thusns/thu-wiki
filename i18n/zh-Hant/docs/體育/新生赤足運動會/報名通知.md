# 新生「健康始於足下」—赤足運動會報名通知

## 宗旨

為了全面貫徹落實中央精神和習近平總書記系列重要講話精神，全面貫徹黨的教育方針，實現《全民健身計劃（2021-2025年）》的目標，努力實現學校體育提高學生體質健康水平、提高學生運動技能、幫助同學形成健康體魄、培育團隊意識和拼搏精神。在校園中，為大一新生搭建體育活動和交流的平台，充分挖掘和調動學生體育鍛煉的積極性，特舉辦2022年新生“健康始於足下” 赤腳運動會。

## 時間、地點

### 比賽時間

2022年10月08日（週六）、10月06日（週四）下午提前工程、拔河計畫10月4-5日（週二和週三的中午和晚上）

### 比賽地點

綜體東側

## 競賽項目

### 赤足

1. 個人：100公尺、60公尺跳繩跑、100公尺二人3足跑、實心球擲遠、跳遠、立定跳遠、1分鐘跳繩（單搖）。
2. 團體：10x60公尺迎面接力（2女+8男）、4x100公尺接力（3男+1女）。

### 非赤腳

拔河（每院系限報一班隊16男+2女）、3分鐘集體跳長繩（包括搖繩隊員，每隊10人，男女不限）、3000公尺（男）、1500公尺（女）、800公尺、2分鐘踢鍵、引體向上（男）。

> 各系在報名前，需進行系上選拔賽，冠軍隊（班）代表系上參加學校新生拔河比賽。

## 參加辦法

1. 以班為單位組隊，正式註冊的2022級新生身體健康者均可報名參賽。
2. 2022級經體班報名參加比賽，依成績錄取相應名次及獎勵（成績不計入「馬約翰盃」團體總分中）。但在報名時名字後面備註“體特”，例如\*\*\*（體特）。
3. 個人項目，每項限報男女各1人每人限報一項，可兼報接力、拔河及3分鐘集體跳長繩。
4. 團體項目：接力、3分鐘集體跳長繩（每單位限報一隊），拔河（冠軍班）。
5. 一個班級女生少（或男生少）影響報名相應參賽項目，依照以下說明報名：
   請系所體幹依附錄一《2022年XX系XX班級名單》及附錄二《2022年新生運動會報名備案表》填寫後，由系所蓋章，最晚於9月28日（週三）中午12點前交至氣膜館前台處，由前台轉姜老師，以備驗學生身分。
   可調整備案的系所情況如下才能申請：
   1. 班級女生人數少於報名項目次項，可一人兼報其他項目。例：車輛學院有6名女生，報名項目有10項，由全部6名女生每人一項報滿6項，剩下4項比賽項目可由1人或多人兼項報名。
   2. 班級男生人數少於報名項目次項，可一人兼報其他項目。例：人文有6名男生，報名項目有10項，由全部6名男生每人一項報滿6項，剩4項比賽項目可由1人或多人兼項報名。
   3. 若一個班級女生或男生只有一人，可依個人體力、專案特徵不限兼項報名。請依個人狀況量力而行。
6. 報名要求
   1. 報名時間：2022年9月23日（週四）開始，至2022年9月28日（週三）24:00截止。
   2. 各單位可登入聖火賽事平台報名，網址： http://tsinghua.bjsh98.com。
   3. 2022年9月30日（週五）12:30-13:15，在東操西看台二樓會議室，進行拔河工程抽籤。

## 錄取辦法

1. 各項目分別錄取前八名。以9、7、6、5、4、3、2、1計分，集體及接力項目得分加倍。
2. 新生團體總分，錄取前十二名並給予獎勵。
3. 若團體總分相等，以單項獲得第一名多者名次列前，再相等以第二名多者列前，以此類推。
4. 依各系運動會得分排出名次併計入2022-2023學年「馬約賽總分中。
5. 獲單項前三名的個人，團體前十二名的單位，分別給予物質獎勵。

## 參賽規則和要求

1. 赤腳項目必須赤腳參賽。
2. 參賽時請攜帶學生證或能證明身分的證件備查。
3. 弄虛作假者，取消該單位比賽成績，通報批評。
4. 具體要求，在領隊會上統一說明。
   1. 領隊會時間：2022年10月3日（週一）20:00。
   2. 領隊會以線上「騰訊會議」的方式進行，騰訊會議帳號：體幹群通知。
