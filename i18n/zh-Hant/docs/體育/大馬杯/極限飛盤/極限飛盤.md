# 「馬約翰杯」極限飛盤

## 比賽宗旨

為促進我校極限飛盤運動的發展與繁榮，提升我校學生極限飛盤運動水平，更好地展現我校學生的精神風采，特舉辦2022-2023學年清華大學“馬約翰杯”學生運動會極限飛盤比賽。

## 比賽方式

為了在普通同學中推廣極限飛盤運動，讓更多的同學參與到極限飛盤運動中來，2022-2023學年「馬約翰杯」極限飛盤比賽分為甲組和乙組，參賽隊伍甲組、乙組的劃分依據《2022-2023馬杯競賽指南》。

### 報名

1. 報名時間：2022年10月5日18:00—10月9日18:00（第4週週三至第4週週日）
2. 本屆比賽對於報名隊伍數量不設上限。
3. 報名表下載：請各系隊長或體育部負責人造訪以下連結下載報名表。
   https://cloud.tsinghua.edu.cn/f/5ccbd718b4174529bf07/?dl=1
4. 報名表提交：請各參賽隊伍務必於2022年10月9日18點前將報名表電子版寄至以下信箱：qingfeithu@163.com
5. 報名表內容必須依要求填寫完整，填寫的報名表統一命名格式為“【**院系名+極限飛盤馬杯+報名表**】”，例如“建築學院極限飛盤馬杯報名表”、“未央書院極限飛盤馬杯報名表”。
6. 確認報名成功後，協會將回覆隊長聯絡群的二維碼，後續通知將在聯絡群組中進行。

### 人員資格與權限

1. 每個系上最多報一支隊伍參加「馬約翰杯」極限飛盤比賽。 **每隊限報6至25名參賽隊員（包括一名隊長和一名精神隊長），其中女生/男生各不少於3名**。
2. 隊員必須是本係正式註冊的**在學學生（包括本科生、碩士生、博士生、交換生）以及教職員**（需根據《2022-2023馬盃競賽指南》的規定出具相關證明）。
3. **領隊**：每隊必設一名，必須由各系團書記或副書記擔任，運動員不得兼任領隊。領隊有責任根據《2022-2023馬杯競賽指南》和本報名辦法，審核報名運動員的參賽資格，督促運動員遵守組委會的規定，鼓勵運動員展現良好的精神面貌。
4. **隊長**：非本隊比賽期間，與清華大學學生極限飛盤協會的聯絡由隊長負責，隊長有責任保持聯繫方式有效。在本隊比賽期間，如遇任何特殊情況，需要隊長出面溝通交流解決。如果隊長無法出席某次比賽，需要隊長指定另一位隊員來擔任本場比賽的隊長。
5. **精神隊長**：每隊必設一名，不得由隊長兼任。精神隊長負責在賽後指導全體隊員進行本場比賽對手的飛盤精神評分，並在結束後將評分錶交​​主辦單位。在本隊訓練、比賽期間，精神隊長有責任對本隊成員的規則認知與使用、犯規與身體接觸、公平意識等方面進行教學與監督。
6. 領隊不在場時，隊長、精神隊長有義務維持本方觀眾的觀賽秩序。
7. 為維護比賽公平，雙方均有權、有責任派出一名記分員監督比數的紀錄。領隊或隊長在比賽結束後需要確認比賽結果，並在記分錶上**對應位置簽字**後方可離開。
8. 比賽時請運動員隨身攜帶**學生證或學生卡、教職員卡**，供當場裁判檢查。否則視為無法證明合法身份，不具備當場比賽的上場資格。
9. **所有參賽隊伍均有權利對所有參賽隊員資格進行監督**。

### 裁決制度

1. 飛盤比賽無論大小均採用「無裁判」的比賽方式，一切比賽爭議由比賽雙方場上隊員和隊長、精神隊長協商解決。
2. 為確保比賽順利、有效率地進行，本次採用「**觀察員制**」。每場比賽均設至少一名“觀察員”，由主辦方清華大學學生極限飛盤協會指派現役飛盤校隊隊員擔任。觀察員僅負責對飛盤規則做出解釋，並在場上隊員主動詢問時提供觀點建議，其判定不具裁決效力。
3. 清華大學學生極限飛盤協會將在準備會上進行有關飛盤規則與飛盤精神的培訓，為確保比賽的順利進行，請各隊的精神隊長務必參加培訓，同時也歡迎所有隊員前來學習交流。

### 準備會

時間暫定為第四週周中，具體時間、地點待通知。準備會兼有**規則解釋、抽籤、精神評分訓練**等部分。飛盤規則與其他比賽有別，請各位隊長務必帶領各自隊伍的精神隊長參加準備會。

### 賽程

#### 小組循環賽

若甲、乙組某組參賽隊伍小於12支，擬採取分兩組進行小組循環賽，每組前四名晉級排名賽（具體分組及晉級規則將視參賽隊伍數量進行一定調整）。
若甲、乙組某組參賽隊伍大於等於12支，則採取分四組進行小組循環賽，每組前兩名晉級排名賽。
小組分組以抽籤決定，根據2021-2022學年「馬約翰盃」極限飛盤比賽的排名分出甲、乙組各四支種子隊伍，同一個小組不會存在兩支種子隊伍。小組賽階段，勝一場積3分，平手一積1分，負1場積0分。若一方棄權，則另一方以11：0取勝，積3分，棄權方積-3分。若雙方棄權，則比賽結果為0:0，雙方各積-3分。小組賽階段，積分較多的隊伍名次列前。

若存在兩支或兩支以上的隊伍積分相同，則依序以下列方式排列名次

1. 棄權較少者，名次列前；
2. 相互比賽積分多者，名次列前；
3. 總淨勝分多者，名次列前；
4. 總得分多者，名次列前；
5. 以擲遠的方式決定最終名次

#### 八強排名賽

排名賽階段，由甲、乙組出線的各八支隊伍參加。若一方棄權，則另一方直接獲勝。若雙方棄權，則雙方皆判負，位列最後兩名。

2. 比賽場地為東棒球場，可允許同時進行兩場五人制極限飛盤比賽。

### 比賽規則

除特殊規定外，其他比賽規則請參考世界飛盤總會（WFDF）2021版極限飛盤規則。
下載連結： https://cloud.tsinghua.edu.cn/d/a15f128ea6074ff8a49b/

#### 特殊規定及需要說明的規定：

1. 比賽場上每隊五名選手，男生和女生至少各有一名，男女比由進攻方決定。 （推薦男女比4:1，3:2或2:3）。如有場上雙方男女生數量不等的情況，經雙方同意可以進行比賽。
2. 每場比賽11分，比賽時間為60分鐘，硬時限為50分鐘（硬時限到達時在結束當前分後，將把領先隊伍的分數加一分作為比賽的結束分），最後先獲得11分，或者在60分鐘內獲得更多分數的一隊獲勝。小組賽階段，如果在60分鐘內兩隊平分，則視為平手。排名賽階段，如果在60分鐘內兩隊平分，則把當前分數加一分作為比賽的結束分，贏得當前分的隊伍獲勝。
3. 6分時中場休息，時長一分半，中場休息後交換場地和進攻防守。
4. 每場比賽共有兩個暫停機會，在比賽開始時和中場休息後每隊各獲得一次，每次暫停時長一分鐘。
5. 每一分開始前可選擇更換上場球員，一分開始後除非特殊因素如受傷，不得更換上場球員。每兩分間換人次不限。
6. 每場比賽開賽後15分鐘內，若比賽一方無法到齊5名報名選手上場，則視為棄權。

### 獎懲

根據《2022-2023馬盃競賽指南》，經過與二級仲裁委員會和體育部的商議，對於比賽做出以下獎懲規定：

1. 清華大學「馬約翰盃」極限飛盤比賽對於甲、乙組最終取得最佳精神獎的隊伍進行獎勵（不涉及馬杯積分）。
2. 若某隊某場比賽有不符合參賽資格的隊員上場，一經檢舉、查實，仲裁委員會將取消該隊比賽資格，並通報批評。
3. 參賽隊伍不得中途罷賽，否則仲裁委員會有權取消該隊本屆賽事中所有剩餘比賽的參賽資格，取消全部成績，同時視嚴重情況決定是否禁止該隊參加下一屆「馬約翰盃」極限飛盤比賽。
4. 對於比賽中雙方對於同一規則理解不一致的矛盾，由雙方隊長向當場觀察員提出質詢，並以觀察員的解讀為準；若雙方仍有較大分歧，則由當場觀察員向仲裁委員會提出質詢，由委員會作出判決。
