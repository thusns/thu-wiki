# 科技英語視聽說（中級、高級）



本門課程慎選，作業十分複雜，每周作業的條目一般可以達到十項以上,並且有“fail one part,then fail the course"一說，老師對中期退課難以容忍，並佈置有大量的假期預習作業和平時作業，預計每天於本課程所花時間在一個小時以上。

對英語提高有需求的同學強烈推薦本門課程，在清華英語課越來越水的今天，王英老師從各個方面嚴格要求學生，全面科學地詞彙量和英語水平等。對每個單字的多種意思都在語境中充分理解，需要大量的背誦和文字工作，對聽英語對話感到熟練，也需要大量的聽力訓練，因此這門課的作業多也就不奇怪了。

王英老師也開設有《字彙的力量》課，據說選了老師三門課的人詞彙量等級可以達到八千。 。 。
