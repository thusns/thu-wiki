# 志願相關資訊
## 志願資源
校內志工資訊大多會在微信公眾號 **「清華大學學生公益」** 中發出。各系的志願組也會進行自己的志工服務，除品牌項目外大多面向系上。
## 星級志工評選
每年5月左右會進行清華星級志工的評選。評選依據[志愿北京网站](http://www.bv2008.cn)上的志工時與項目數進行評選，由低到高依序為一星到五星志工。具體規則如下（摘自「清華大學紫荊志工分級嘉許辦法」）：
* 登入志願北京平台註冊並填寫個人信息，以註冊成為志願者，加入“清華大學紫荊志願服務總隊”這一志願團體，至少參加過**一次**志願服務並且獲得認證時間後，獲得 **“一星級紫荊志願者”** 稱號。
* 志工服務認證時間累積達到**20**小時，獲得 **「二星級紫荊志工」** 稱號。
* 志工服務認證時間累積達到**50**小時，獲得 **「三星級紫荊志工」** 稱號。
* 志工服務認證時間累計達到**120**小時，且至少參加過**3次**不同的志工項目，經審核後獲得 **「四星級紫荊志工」** 稱號。
* 志工服務認證時間累計達到**200**小時，且至少參加過**5次**不同的志工項目，經審核後獲得 **「五星級紫荊志工」** 稱號。
除此之外，每年的獎學金評比中，還會有「志願優良獎學金」一項，以嘉獎在志工服務上表現突出的同學。
