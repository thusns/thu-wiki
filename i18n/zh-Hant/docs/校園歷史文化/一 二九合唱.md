# 一二·九合唱

## 一二·九運動清華歷史

1935年，日本人在華北製造華北事變，推動所謂華北自治運動，華北形勢岌岌可危，時為清華大學學生的蔣南翔悲憤地喊出：

> 「華北之大，已經安放不得一張平靜的書桌了」。

當時，正在清華大學社會學系讀大四的陸璀同學，20歲剛出頭，是清華學生救國委員會委員，參加了轟轟烈烈的一二·九愛國運動，她手持話筒發表激情演講的照片被一個至今不為人知的攝影愛好者拍攝後寄到了上海的《大眾生活》雜誌。 1935年12月9日上午10點，清華學生冒著凜冽的寒風從清華園向北京城走去，途中他們不停向沿途群眾散發油印的《告全國民眾書》。在和燕京大學的同學會合後，學生們來到城門緊閉的西直門下，高呼口號，但是事先已經獲悉情況的國民黨軍警不敢開門，最後學生們臨時決定就在西直門的城牆旁邊召開群眾大會，並推舉陸璀向群眾講話。當時，臨時找來一塊小方凳，陸璀站在那個凳子上，左手捏著一頁紙，右手拿著一個大麥克風，開始發表激情演說。陸璀說：

> “北平是我們中國人的北平，現在中國人不能進去，但反而日本人在城裡橫行霸道，欺負我們的老百姓，請問終究北平最終是誰家的天下呢？”

12月16日，北平舉行了更大規模的示威遊行活動，陸璀因從宣武門爬進城門被捕，巧遇美國記者埃德加•斯諾，在警察的包圍中陸璀接受了斯諾採訪，斯諾以《中國的貞德被捕了》為題在美國的報紙上發表新聞，一二·九運動和陸璀的名字世界聞名。
