# ejercicio físico bajo el sol

Los estudiantes que toman cursos de educación física en el primer a tercer año de los cursos universitarios deben participar en actividades de ejercicio físico bajo el sol y descargar la aplicación "Le Power" para registrarse para hacer ejercicio. Para obtener más información, consulte los anuncios emitidos por cada departamento.
