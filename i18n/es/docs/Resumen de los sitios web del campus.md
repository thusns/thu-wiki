# Resumen de los sitios web del campus

## Sitio web de servicio
Sitio web oficial de Tsinghua (tsinghua.edu.cn): el sitio web oficial de Tsinghua para el público, donde puede encontrar información como información promocional, configuración del departamento y programas de capacitación profesional (https://www.tsinghua.edu.cn/jyjx/bksjy/bkzy.htm)
Portal de información/info(info.tsinghua.edu.cn)
Portal de enseñanza/académico (academic.tsinghua.edu.cn)
Biblioteca (lib.tsinghua.edu.cn)
Aula de lluvia del estanque de lotos (pro.yuketang.cn)
Escuela en línea (learn.tsinghua.edu.cn)
Estudiante Tsinghua (student.tsinghua.edu.cn)
Servicios para usuarios de información (its.tsinghua.edu.cn)
Sistema de servicio de identidad electrónica (id.tsinghua.edu.cn)
Práctica de Tsinghua (shijian.student.tsinghua.edu.cn)
Plataforma de referencia docente (reservas.lib.tsinghua.edu.cn/): puede consultar la referencia docente utilizada por muchos cursos de la escuela.
Disco en la nube de Tsinghua (cloud.tsinghua.edu.cn/)
Sistema de selección de cursos (zhjwxkyw.cic.tsinghua.edu.cn/xklogin.do)
Servicio de alojamiento de códigos de la Universidad de Tsinghua (git.tsinghua.edu.cn)
