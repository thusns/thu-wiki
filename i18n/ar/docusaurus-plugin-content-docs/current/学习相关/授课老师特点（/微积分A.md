# حساب التفاضل والتكامل أ
#### وانغ تشينغروي
1. **سرعة المحاضرة أسرع**، مما يمكن أن يوفر الوقت ويستخدم وقت الفصل للتعامل مع التمارين بعد كل فصل (في الواقع للحفاظ على نفس التقدم مثل الفصول الأخرى)
2. **عبء العمل المعتدل**
3. أسلوب المحاضرة: رومانسية طلاب العلم (بعض قصص الرياضيات الممتعة)، ليست جادة
4. **لن يتم استدعاء أي أسماء** قبل الفصل، ولكن سيتم اختيار الأشخاص بشكل عشوائي **للإجابة على الأسئلة** أثناء الفصل. إذا لم يكن الشخص حاضرا، فسوف يكتب ذلك.
