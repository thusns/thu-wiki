# 動物園

### 北京動物園

距離: **7.6km**
営業時間：7:30～19:30（最終入場19:00）
チケット料金：学生7.5円
はじめに：100年の歴史があります。中国で最も古くからある動物園であり、最も多くの動物が飼育されています。大人も子供もそこに行くのが大好きです。
### 北京野生動物園
距離: **57.1km**
営業時間：9:00～17:00
チケット料金：学生85円
はじめに: ここの動物は科、属、地域によって分類されていません。子どもたちは参加し、体験し、交流し、楽しむことができます。
### 国立植物園北園
距離: **10.2km**
営業時間：6:00～20:00
チケット料金：学生￥2.5
はじめに：植物にはたくさんの種類があります。主な訪問ポイントは温室展示エリアであり、その他にも多くの景勝地や史跡があります。レクリエーションやレジャーに最適な場所です。
