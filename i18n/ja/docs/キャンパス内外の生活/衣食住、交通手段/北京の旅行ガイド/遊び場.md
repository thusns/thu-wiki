# 遊び場

### ユニバーサル北京リゾート

距離: **34.8km**
営業時間：10:00～19:00（最終入場18:00）
チケット料金：528円
概要: アジアで 3 番目、世界で 5 番目のユニバーサル スタジオ テーマ パークは、テーマ パークを愛する無数の若者を魅了しています。
### 石景山遊園地
距離: **14.9**
営業時間：9:00～16:30
チケット料金：学生5円、パーク内アイテム含む別途料金
はじめに: 北京に建てられた最古の遊園地である観覧車は、数え切れないほどの人々の幼少期の思い出です。
### 北京ハッピーバレー

距離: **21.3km**
営業時間：9:30～22:00
チケット料金：18歳以下[258円]、身長1.5メートル以下[193円]、大人297円
紹介: 美しい景色を楽しみ、パフォーマンスを鑑賞し、エキサイティングで興味深い乗り物をたくさんプレイできる、家族全員に適したテーマパーク。
