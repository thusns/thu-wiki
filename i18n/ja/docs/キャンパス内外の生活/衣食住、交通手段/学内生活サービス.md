# キャンパス内のスーパーマーケット

## 天猫スーパーマーケット（南区7号館）（清汾園の隣）

清汾園南東角7番階下、営業時間：8:30 – 23:30

* お菓子や文房具、様々な日用品が買えます。
* パンケーキやたこ焼き、焼き冷麺などを販売するお店もあります。
* 店内には電子レンジ、椅子、充電コンセントもございます。
* チェックアウトせずにキャンパスカードまたはAlipayで支払うことができます。印刷所、セブンハーバーズ、ナインミルクティーショップ、コインランドリー（スーツケースの修理もできるそうです）、電化製品店（充電ケーブルやネットワークケーブルなどを販売）もあります。

## 天猫スーパーマーケット（Cビル店）

C館B1 営業時間：8:30～23:30

* 種類も充実しており規模も大きく、無人レジでの支払いにはAlipayも利用可能です。
* スナックバーやハッピーレモンなどのさまざまな商品は、タオバオのモバイルアプリ「淘仙達」を通じて購入し、自宅まで届けてくれます（39元以上の購入で配送料は無料）。
* 同様に、電子レンジ、椅子、充電ソケットもあります。
* C 棟の地下 1 階には ==眼鏡店== (ただし、費用対効果を求めるなら、キャンパス外の中関村に行くことをお勧めします) と ==本屋== があります。

## 天猫スーパーマーケット（関潮源店）（地下1万人）

関州花園 G/F 営業時間：9:00 – 21:00
(流行期間中の営業時間は10:00～19:00)

* 商品の種類、店内設備、支払い方法は前の 2 つと同様ですが、関州園の地下階にもギフト、文化教育用品、果物など、さまざまな商品が揃っています。
* 地下階にある ==Digital Repair Shop== では、携帯電話の画面を修理できます。
* 関州園からそれほど遠くない都豊書店の隣に==眼鏡店==もあります。
* 万湾（関州園）の1階に==スーツショップ==があり、スーツを借りることができます。

## 清華蘭園コミュニティ ビジネス センター

昭蘭病院内 営業時間：9:00～20:30
