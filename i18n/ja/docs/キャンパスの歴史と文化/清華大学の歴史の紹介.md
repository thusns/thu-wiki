# 清華大学の歴史の紹介

清華大学の前身である清華学院は 1911 年に設立され、1912 年に清華学校に改名されました。1928 年に国立清華大学に改名されました。 1937年に抗日戦争が勃発すると、長沙に南下し、北京大学、南開大学とともに国立長沙臨時大学を設立した。 1938 年に昆明に移転し、国立西南連合大学に改名されました。 1946 年に清華大学に戻り、現在は文系、法律、科学、工学、農学を含む 5 つの大学と 26 の学部を擁しています。

1952 年に全国の単科大学が再編された後、清華大学は学際的な工業大学となり、全国の工学および技術人材の育成に重点を置き、「紅い技術者のゆりかご」として知られていました。改革開放以来、清華大学は世界クラスの大学を建設するという長期目標を徐々に確立し、力強い発展の新時代に入った。同校は科学、教養、医学、経済管理の分野を復活または新設し、大学院と継続教育大学を設置した。 1999 年に中央美術工芸学院が合併し、清華大学美術学院が設立されました。 2012 年、中国人民銀行大学院は清華大学 PBC 金融学院に統合されました。国家と社会の強力な支援を受け、「211プロジェクト」、「985プロジェクト」、「ダブルファーストクラス」建設の実施を通じて、清華大学は人材育成、科学研究、社会福祉、文化の継承と革新、国際協力と交流において大きな進歩を遂げた。現在、清華大学には 21 の大学と 59 の学部があります。科学、工学、文学、芸術、歴史、哲学、経済学、経営学、法律、教育、医学、学際的科目を含む12の分野を擁する、総合的で研究指向の開かれた大学となっています。

清華大学は将来に向けて、「継続的な自己改善と道徳的誠実さ」の校是と「行動は言葉よりも雄弁である」の校風を守り、「中国と西洋の融合、古代と現代の結合、リベラルアーツとサイエンスの浸透」という学校運営スタイルと「専門と専門の両方、総合的な発展」という教育の特徴を堅持する。道徳の育成と人材の育成を基本任務とし、国家に奉仕することを最高の目標とし、規律の建設を発展の基礎とし、改革の深化を強力な推進力とし、党の建設を強力な保証として強化し、引き続き改革を深化させ、「二重一流」建設を実現し、内包的な質の高い発展を実現し、世界一流の大学の先頭に立つよう努力し、国家の発展、人民の幸福、人類文明の進歩に新たかつより大きな貢献をする。
