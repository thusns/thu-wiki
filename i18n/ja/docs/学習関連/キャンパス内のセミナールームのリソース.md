# キャンパス内のセミナールームのリソース

清華ホームネットワーク公式アカウントでは以下のセミナールームを予約できます。利用の際は3人分の学生証を所持し、教務棟管理室で鍵の交換が必要です。
* 清華学院セミナールーム：6～8席のセミナールームが4室あります。
* 4つの教育セミナールーム: 6〜10席のセミナールームが12室あります。
* 教育セミナールーム6室：6名定員のセミナールームが3室あります。
* ファトゥ地下セミナールーム：6人掛けのセミナールームが2室あります。

Student Tsinghua（ウェブサイト、公式アカウント、ミニプログラム）では、以下のセミナールームを予約できます。
* C棟2階：10名用セミナールームが3室、20名用セミナールームが4室あります。
* C棟3階には小セミナー室（2名）6室、中セミナー室（11名）4室、大セミナー室2室（30名程度）があり、
* 南エリア地下：10名から200名まで収容可能な研究室が12室あります。
