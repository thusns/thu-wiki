# コンピュータ言語とプログラミング
#### スオ・ジンリ
1. 授業のペースは速く、知識のポイントをしっかりと理解できます。例を使用して手順を説明しますが、事前にプレビューする必要があります。 3 時間のクラスでは、通常、前の章の内容を 2 つのクラスでカバーし、1 つのクラスで新しい章を開始します (プレビューを容易にするという考えです)。
2. 教室の雰囲気は和やかで活気があります
3. **課題**には通常 5 ～ 6 つの質問がありますが、新しい章が含まれるため、**難易度が高くなります** (課題はプログラムが正しいかどうかを自動的に検出できる OJ で提出され、無制限に提出できます。DDL より前に合格することができます)。
4. 授業中に名前を呼ばれたり、質問されることはありません。
