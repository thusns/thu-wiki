# 英語のリスニングとスピーキングのコミュニケーション
#### グリマ ジョン・ポール・クリストファー
1. 各授業には対応するテーマ（幸福、芸術など）があり、授業内容はノートの取り方によって補足されます。
2. 放課後の宿題にはリスニングやスピーキングのパートは基本的になく、700～800ワードの小論文を書かせられます。
3. スピーキング試験やグループ課題はコースのトピックに関連しています
4. 授業中に親切に質問に答えてあげることで、発言することを恐れる生徒の励みになります。
