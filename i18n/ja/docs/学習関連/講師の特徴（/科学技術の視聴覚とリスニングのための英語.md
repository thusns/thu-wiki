# 科学技術英語 視聴覚・リスニング（中級、上級）



このコースは慎重に選んでください。割り当ては非常に複雑です。通常、週に 10 件以上の課題があります。 「一部を失敗すれば、コースも失敗する」ということわざもあります。教師はコースの途中で退学することを容認せず、休暇の下見の宿題と通常の宿題を大量に課します。このコースの受講時間は毎日1時間以上になることが予想されます。

このコースは英語力を向上させる必要がある学生に強くお勧めします。現在、清華大学の英語コースの人気がますます高まる中、王英先生は、総合的かつ科学的な語彙力や英語力など、あらゆる面から学生に厳しく要求しています。文脈の中で各単語の複数の意味を完全に理解するには、多くの暗記と単語作業が必要であり、英会話を聞き取れるようになるには多くのリスニングトレーニングも必要であるため、このコースの宿題が多いのも当然です。

王英先生は「語彙の力」というコースも提供しています。先生の3つのコースを受講すると、語彙レベルは8,000までになると言われています。 。 。
