## 関連サイト

1. 清華大学情報ポータル

http://info.tsinghua.edu.cn/

学務部では、免除申請の際に満たすべき条件、登録時期、免除登録システムの操作マニュアル、資格審査要件等を含む試験免除及び大学院研究の推進に関するお知らせを、昇格・免除業務の開始前にホームページの「学務お知らせ」欄に掲載します。

2. 清華大学の研究および採用ウェブサイト

https://yz.tsinghua.edu.cn/ 清華大学研究採用プラットフォームは、試験なしで大学院研究への登録通知を発行します。各学部の評価免除および入学手続きは、清華大学大学院入学ウェブサイトから確認するか、各学部のホームページにアクセスしてください。時間は各部門の発表により異なります。

3. 清華大学大学院生申請サービスシステム

(旧バージョンの情報情報ポータル - 総合 - 左クイック ナビゲーション - 卒業欄 - 試験無料プロモーションの個人アカウントを通じてログインするか、新バージョンの情報情報ポータル - マイ ワークベンチ - 試験無料プロモーションを通じてログインするか、次の Web サイト: https://yzbm.tsinghua.edu.cn/ndLogin を通じて清華大学大学院生申請サービス システムに直接アクセスし、必要に応じて登録およびログインしてください)

その年に学内外で博士・修士課程の無試験推薦に参加する本学の学部生（本校在学生および学外の大学院生を含む）は、学校が指定する時間内に清華大学大学院出願サービスシステムにログインし、無試験推薦の申請情報を入力しないと無効となります。このシステムを利用することで、推薦枠の獲得状況（学部が管理）や入学の合否（大学院入試部門が管理）などの情報を確認することができます。

4. 国が推奨する優秀な学部新卒者の無試験大学院進学のための情報公開・管理サービス制度

http://yz.chsi.com.cn/tm

このサイトは文部科学省の推薦・減免制度です。これは、国の推薦および免除業務のための統合された情報提出および公開プラットフォームおよびオンライン申請および入学システムです。資格の審査・確認、申請・入学、推薦学生（修士推薦学生、博士直属学生を含む）の届出・開示等の関連業務は、この制度を通じて行わなければなりません。割り当てを取得して受け入れられたすべての免除学生は、システムにログインし、教育省の要件に従って対応する操作を実行する必要があります。

## 免除要件

1. 本校から「推薦資格」と「推薦枠」を取得する。

2. 入学を希望する学術研究機関から「入学枠」を取得します。

## リンク

研究推進制度は、どのレベルにおいても原則として年に1回公表されます。

### おすすめリンク

本校では毎年、情報学務報に研究推進業務のお知らせを掲載しています。

学部が毎年発行する推奨メソッド（一部の学部では長期前提履修規程を策定し、研修計画に添付している）。

### リンクを受信中

各学科の試験免除や入学手続きについては、本校の大学院入学ウェブサイト https://yz.tsinghua.edu.cn の学科案内 - 学部 - 推薦入学 - お知らせ・お知らせ からご覧いただくか、本校各学科のホームページからご確認いただけます。時間は各部門の発表により異なります。 （**学校を越えて入学推薦を受けた学生も、この方法を参考にして他の学術研究機関への入学の評価や入学手続きを確認することができます**）
