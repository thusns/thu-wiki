# 軍事訓練

### 軍事的スキル

1. **注意して立つ、休む、向きを変える、座る、しゃがむ、立ち上がる、足並みを揃えて歩く、足並みを揃えて歩く**
   （走行中・走行中の旋回は未調査）
2. **ミリタリーボクシング**
3. **スプリットステップ** (つまり、東草の演壇の前で、行進からガチョウのステップ、そしてタンデム行進に変わります)
4. **実績報告**: 軍事ボクシング、暗殺訓練、国旗言語訓練、短剣訓練 (各大隊がいずれかの訓練を選択)
5. **射撃** (近年は実弾ではない)
6. **練習** (20キロ)

スコア: ほとんどの場合 3.6、優れたパフォーマンスの場合 4.0

### 軍事理論

**前年度の質問**と教師**のクラスの質問**を見てください。

(ヒント: 過去の質問バンクはキャンパス内の印刷所で購入することも、先輩から借りることもできます)
