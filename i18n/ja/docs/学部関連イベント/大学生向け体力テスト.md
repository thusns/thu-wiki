# 大学生向け体力テスト

## 概要

毎年秋学期に身体検査があります。 1年生は集中身体検査を受けます（身体検査では身長、体重、肺活量も測定されます）。 2・3年生は集中体力検査項目とその他の項目（身長、体重、肺活量）に分かれています。

## 場所

集中身体検査は通常、東草の北東の角から入場します。準備作業を行った後は、現場スタッフの指示に従って作業を行うことができます。

その他の身体検査項目は、東草西館の台北ポイント身体検査センターで実施されます。

## 物理テストガイド

学生証だけ持ってきてください。現地には沸騰したお湯やブドウ糖水などが用意されています。

テストと毎日の練習の間には大きな違いがあります。呼吸器に過敏症のある人は、中距離のランニングを終えた後に不快感を感じることがあります。走った後はマスクを着用して緊張を和らげることができます。
