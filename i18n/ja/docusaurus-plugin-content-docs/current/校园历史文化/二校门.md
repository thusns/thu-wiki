# 第二校門

## 外観

第 2 キャンパスゲートは、清華大学の主要道路の 1 つである清華路にあります。清華大学を代表するランドマーク建築の一つであり、清華大学のシンボルとされています。第二校門は、3つのアーチと青いレンガと白い柱を備えたクラシカルで優美な「アーチ型」の建物です。鴨居には清末の偉大な学者、那通の筆跡で「清華園」の三文字が刻まれている。清華路に立って北の第 2 校門を見ると、遠くに清華講堂、日時計、清華学院が見えます。

第 2 キャンパス門は清華大学の最も初期のメインキャンパス門で、1909 年に建てられました。1933 年にキャンパスが拡張され、庭の壁が外側に移動され、新しい門 (現在の西キャンパス門) が建てられました。以来、この最初期の校門は「第二の校門」と呼ばれるようになりました。

1966年8月24日、第二校門は「四老」としての「清華大学紅衛兵」によって押し倒され、破壊された。 1991 年の清華大学創立 80 周年の際、清華大学同窓生からの寄付により、第 2 門が元の場所に再建されました。

春、夏、秋、冬、毎年、時間はあっという間に過ぎていきます。キャンパスの主要道路に立つ第 2 キャンパスゲートは、風と雨の中で清華大学の歴史と発展を静かに見守っています。これは清華大学の特徴的なシンボルであるだけでなく、勤勉で現実的で名誉や不名誉に動じない清華人の長年の気質の象徴でもあります。
