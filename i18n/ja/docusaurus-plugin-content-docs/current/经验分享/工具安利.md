# ツールアムウェイ

## 電子書籍の入手方法

1. 高麗人参教育サービスプラットフォーム: http://reserves.lib.tsinghua.edu.cn/，内含许多教材，如没找到还可以向图书馆请求教材。
2. Z ライブラリ (マジック インターネット アクセスが必要)
3. 国立図書館資料連合 http://www.ucdrs.superlib.net/
4. Jiumo 書籍検索 https://www.jiumodiary.com/
5. PDF ドライブ https://www.pdfdrive.com/
6. ロアフリー https://ebook2.lorefree.com/
7. タオバオで本を探すと1冊あたり2～3元くらいかかります。
