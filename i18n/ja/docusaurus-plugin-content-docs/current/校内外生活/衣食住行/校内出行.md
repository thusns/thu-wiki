# キャンパス内旅行

## スクールバス

* キャンパスバスは「手を振って最寄りの場所で乗降」しており、大きな荷物も持ち込めます。
  * 「清華キャンパスバス」WeChat アプレットを使用して、キャンパスバス路線の出発状況を監視できます。
  * 学内の方は清華IDカードで無料、学外の方は1人2元（土日祝日は1人3元）で乗車できます。
* 外環：平日7時20分～18時、土・日・祝日8時30分～17時30分。冬季・夏季休暇中の営業につきましては、お知らせする場合がございます。
* 内環状：平日7:40～11:10、12:40～17:25、土・日・祝日休み、冬季・夏季休業あり
* 学生ホットライン：平日午前7時40分、午前9時20分、午後1時、午後2時50分、土曜・日曜・祝日は休業、冬季・夏季休暇中は休業
* 特別な医療ライン：月曜日、水曜日、金曜日は北京大学第三病院に行き、火曜日と木曜日は西園病院に行きます。学校病院を 8 時に出発し、シニア アクティビティ センターに 8 時 5 分に停車します。

**_詳しくは「清華大学公式サイト」の「清華大学について」-「実用情報」-「学内交通」をご覧ください_**
