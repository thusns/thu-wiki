# 商店街
### 南鑼鼓祥

距離: **10.3km**
営業時間：10:00～21:00
チケット料金：スナックストリートです。チケットが必要な場合は直接入場してください。
はじめに: 北京の有名なスナック歩行者専用街には、古い北京の胡同様式と本物の北京文化を体験するために数え切れないほどの若者が集まります。

### 王府井歩行街

距離: **12.9km**
営業時間：ああこれ
チケット料金：ああこれ
概要: 数百年の歴史を持つ有名な商業歩行者専用道路で、昔の北京の生活風景を高度に復元した没入型体験空間です。



### 前門街
距離: **14.2km**
営業時間：終日営業
チケット料金：無料
概要: 古くから北京で最も有名な商店街です。多くの由緒あるブランドと世界中からの軽食のコレクションがあり、古き北京の雰囲気を味わえます。
### 北京桂街
距離: **11.2km**
営業時間：終日
チケット料金：なし
紹介: 夜のグルメが集まる場所です。夜は明るく照らされています。ネット有名店も多く、行列ができています。
### 五道営胡同
距離: **9.km**
営業時間：終日
チケット料金：無料
概要: 長さは 600 メートルを超え、面積は小さいです。食べ物、コーヒー、バー、衣料品、その他のユニークなショップが揃っています。
