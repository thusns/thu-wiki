電子 ID サービス システム (ID システム) https://id.tsinghua.edu.cn を使用してパスワードを変更し、携帯電話番号をバインドします。

### パスワードを変更する

1. IDシステム
2. セルフサービス システム http://usereg.tsinghua.edu.cn
3. 「清華大学情報サービス」エンタープライズ WeChat ID 認証アシスタント

### パスワードをリセットする

1. セルフサービス リセット (アカウントを携帯電話にバインドする必要があります): ID システムの [既にアカウント] ページで、[パスワードを忘れた場合] をクリックして SMS 確認コードをリセットします。または、情報ポータルのホームページの「パスワードを忘れた場合」よりお問い合わせください。
2. 手動リセット: Lee Shau Kee B104 User Service Hall に行きます。必要書類： 直接申請する場合はキャンパスカードを持参してください。代理で申請する場合は、自分のキャンパスカードと申請担当者のキャンパスカードを所持する必要があります。コピーは無効です。
3. 電子メールによる申請: キャンパス カードを手に持って自撮り写真を撮り (カード表面の学生番号と名前がはっきりしている必要があります)、「パスワードのリセット」というタイトルの電子メールを its@tsinghua.edu.cn に送信します。

## キャンパスネットワーク

### キャンパスネットワーク料金表

学校に正式に登録された学部および大学院アカウント
基本サービス: 動的 IPv4、IPv6 アドレス、5 つのネットワーク権限、1 つの電子メール アドレス。
費用: 0 元/月。流行中は、50 GB を超える学外の IPv4 受信トラフィックには料金がかかりません。つまり、無制限に無料で使用できます。

### ケーブルネットワーク

インターネット デバイスをネットワーク ケーブルで壁のネットワーク ポートに接続した後、ブラウザを開いて認証システムの URL http://login.tsinghua.edu.cn を入力するか、情報ポータル http://info.tsinghua.edu.cn にアクセスしてジャンプします。次に、学内ネットワーク認証ログインページ（紫色）で学内ネットワークのアカウントとパスワードを入力し、「ネットワークに接続する」をクリックすると、学内ネットワークに接続でき、ネットワークリソースにアクセスできるようになります。

### ワイヤレスネットワーク

「清華」「清華-」で始まるWi-Fiはキャンパス無線ネットワークです。接続後、認証ログインページ（オレンジ色）が自動的に表示されます。 http://login.tsinghua.edu.cn にアクセスするか、情報ポータル http://info.tsinghua.edu.cn にアクセスしてジャンプすることもできます。次に、学内ネットワーク認証ログインページ（紫色）で学内ネットワークのアカウントとパスワードを入力し、「ネットワークに接続する」をクリックすると、学内ネットワークに接続でき、ネットワークリソースにアクセスできるようになります。
