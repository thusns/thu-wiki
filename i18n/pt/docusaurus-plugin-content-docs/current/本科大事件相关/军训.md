# treinamento militar

### habilidades militares

1. **Fique em posição de sentido, descanse, vire, sente-se, agache-se, levante-se, ande no mesmo passo, ande no mesmo passo**
   (As voltas durante a corrida e a viagem não foram examinadas)
2. **Boxe Militar**
3. **Passo dividido** (isto é, em frente à tribuna de Dongcao, muda de marcha para passo de ganso e depois para marcha em tandem)
4. **Relatórios de desempenho**: Boxe militar, exercício de assassinato, exercício de linguagem de bandeira, exercício de adaga (cada batalhão seleciona um dos exercícios)
5. **Tiro** (sem munição real nos últimos anos)
6. **Prática** (20 quilômetros)

Pontuação: 3,6 para a maioria, 4,0 para excelente desempenho
