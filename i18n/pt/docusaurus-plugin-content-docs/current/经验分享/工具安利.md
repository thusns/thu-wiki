# Ferramentas Amway

## Como obter e-books

1. Plataforma de serviço de ensino de ginseng: http://reserves.lib.tsinghua.edu.cn/，内含许多教材，如没找到还可以向图书馆请求教材。
2. Biblioteca Z (requer acesso mágico à Internet)
3. União de Referência da Biblioteca Nacional http://www.ucdrs.superlib.net/
4. Jiumo Pesquisa Livros https://www.jiumodiary.com/
5. Unidade PDF https://www.pdfdrive.com/
6. Lorefree https://ebook2.lorefree.com/
7. Pesquisar livros no Taobao custa cerca de 2 a 3 yuans/livro.
