# SRT

No início de cada semestre haverá aprovação do projeto e inscrição no projeto SRT. Preste atenção aos grupos de informações e notificação do departamento em tempo hábil; a sequência de tempo é primeiro para os alunos se inscreverem no projeto e depois para os alunos se inscreverem. O sistema SRT está na coluna de informação-aprendizagem. Observe que ao se inscrever, “Projeto aprovado” significa que o professor aprovou o projeto, mas nenhum aluno se inscreveu; "Registrar" significa que os alunos se inscreveram.
Recomenda-se que os alunos enviem um e-mail ao professor para comunicação o mais rápido possível após (ou antes) da inscrição.

## Guia do usuário do sistema SRT

### Aplicação do projeto

1. Clique em "Inscrição do Projeto" na página inicial, preencha o formulário de inscrição do projeto conforme necessário, "\*" é obrigatório e, a seguir, clique no botão "Enviar" para enviar a inscrição ou clique no botão "Salvar Temporariamente" para salvar temporariamente as informações preenchidas.

2. Se as informações estiverem armazenadas temporariamente, na página projeto atual-meu projeto, clique em "Confirmar" e envie diretamente a inscrição do projeto. Clique em "Excluir" para excluir o aplicativo do projeto. Clique em "Visualizar/Modificar Aplicativo" para entrar na página de modificação para modificar as informações do projeto. Nota: Somente projetos não confirmados no lote atual podem ser modificados e outros lotes não podem ser modificados.

3. Cada solicitação de projeto temporário deve ser confirmada antes que a revisão subsequente do projeto possa ser realizada.

4. Após confirmar a inscrição, clique em “Visualizar inscrição” para navegar por todo o conteúdo preenchido.

### Registro de estudante

1. Clique em “Registro de Aluno” na página inicial para entrar na página do projeto cadastrado e visualizar o lote atual de projetos cadastrados. Leia atentamente as instruções de inscrição e clique em “Ver projetos que podem ser inscritos” para entrar na lista de projetos que podem ser inscritos.

2. Pesquise o projeto de acordo com as condições de pesquisa e clique no nome do projeto para visualizar o conteúdo da aplicação do projeto. Clique em “Preencher inscrição” para se inscrever no projeto. 3. Após preencher o formulário de inscrição conforme necessário, clique em “Enviar” para confirmar diretamente a inscrição e clique em “Salvar Temporariamente” para salvar temporariamente as informações preenchidas.

4. Após salvar temporariamente, na página do projeto cadastrado, clique no botão “Visualizar/Modificar” para modificar as informações cadastrais; clique em “Confirmar” para confirmar o cadastro; clique em "Excluir" para excluir o aplicativo de registro.

5. Os pedidos de registo não confirmados após o período de registo são automaticamente invalidados.

6. Após o registro, você pode verificar as informações de revisão do registro na página do projeto atual do qual você está participando.

### Revisão de registro

1. Clique em "Revisão de Registro" na página inicial para entrar na página do projeto atual, selecione a guia "Projetos iniciados por mim", se o projeto for finalmente aprovado e alguém se inscreveu, clique em "Visualizar Status de Registro/Revisão de Registro" e a janela de revisão de registro aparecerá para revisão de registro.

2. Para os alunos que ainda não foram avaliados, clicar em “Preencher” para prosseguir com a análise cadastral. Não pode ser modificado após o envio. Para os alunos que foram avaliados, clique em “Visualizar” para visualizar o pedido de inscrição.

3. O patrocinador do projeto pode definir “se aceita inscrições” durante a fase de revisão das inscrições. Se selecionar “Sim”, o projeto aceitará inscrições; se selecionar “Não”, o projeto deixará de aceitar inscrições e os alunos não poderão visualizar o projeto na lista de projetos que podem ser inscritos.

### Conclusão do projeto

1. A ordem de resposta às perguntas geralmente é para que os alunos respondam primeiro às perguntas e depois para os professores.

2. Se o aluno for o patrocinador do projeto, clique em "Conclusão do Projeto" na página inicial para entrar na página do projeto atual, encontre o projeto que precisa ser concluído, clique em "Conclusão do Projeto", a janela de conclusão do projeto aparecerá, clique em "Preencher" no item de conclusão do projeto do patrocinador do projeto, preencha os comentários do patrocinador do projeto para cada aluno participante e clique em "Preencher a experiência do patrocinador do projeto e os resultados sugeridos" para concluir o projeto individual.

3. Se um aluno for participante, clique em "Conclusão do Projeto" na página inicial para entrar na página do projeto atual, encontre o projeto que precisa ser concluído e clique em "Conclusão do Projeto" para responder diretamente à questão individual.

4. O projeto concluído pode ser visualizado na página do projeto concluído. Clique em “Conclusão do Projeto” para visualizar os comentários do patrocinador do projeto, comentários dos professores, resultados e outras informações.

### Perguntas frequentes

### 1. Quais são os requisitos para os professores das escolas participarem da inscrição no programa SRT?

Professores de escolas com títulos profissionais intermediários e superiores podem solicitar aprovação de projeto.

### 2. Quais são os requisitos para os alunos atuais se inscreverem no programa SRT?

O programa SRT não está aberto a estudantes de pós-graduação. Alunos de graduação do primeiro ao terceiro ano podem solicitar aprovação do projeto.

### 3. Quando é o momento da inscrição no plano SRT?

Há duas aprovações de projetos SRT por ano letivo, e os prazos de aprovação dos projetos são no início do semestre de outono/primavera.

### 4. Qual o procedimento de candidatura ao plano SRT?

Login do candidatohttp://info.tsinghua.edu.cn/，在教学--SRT栏目下按照说明填写立项申请表并确认提交。

Se o candidato for estudante, deverá solicitar avaliação ao instrutor após a confirmação do envio da inscrição do projeto.

### 5. Quantos projetos SRT podem ser inscritos para cada aprovação de projeto?

Você pode se inscrever em até 2 projetos no mesmo lote.

### 6. Quantos alunos podem ser aceitos em cada projeto?

Os candidatos podem determinar o número de pessoas admitidas no projeto com base nas circunstâncias específicas do projeto. O número recomendado de convidados é de 3 a 5 pessoas.

### 7. Como determinar os créditos de um projeto?

Os créditos do projeto são de 1 a 3, com um máximo de 2 créditos se o projeto for implementado por meio ano e 3 créditos se o projeto for implementado por um ano.

### 8. Existe alguma exigência quanto ao tempo de execução do projeto?

O tempo de execução do projeto geralmente varia de meio ano a um ano.

### 9. Qual é o processo de aprovação do projeto do plano SRT?

Após o prazo de inscrição do projeto, o Escritório de Assuntos Acadêmicos resumirá as informações básicas e a revisão do formato do projeto, e organizará especialistas do grupo diretor de planejamento SRT de cada departamento para revisar o projeto. Os candidatos podem verificar o status de aprovação de projetos individuais online. Os projetos aprovados estarão abertos para inscrição dos alunos online.

### 10. Quando é o horário de inscrição no programa SRT?

Existem 2 inscrições SRT por ano letivo, e os horários de inscrição são na 5ª e 6ª semanas do semestre outono/primavera. Alunos de graduação de todas as séries podem se inscrever no projeto SRT. 

### 11. Qual é o procedimento de candidatura ao programa SRT?

Login do Alunohttp://info.tsinghua.edu.cn/，在“学习-SRT(新版)-Inscrição de Aluno-Confira a lista de projetos SRT na coluna “Ver Projetos para Inscrição” e selecione o projeto de seu interesse para se inscrever.

### 12. Como o projeto aceita inscrições de alunos?

Após o patrocinador do projeto concordar em aceitar, o registro é estabelecido. Os alunos aceitos não poderão se inscrever em outros projetos até que o projeto seja concluído ou o professor aprove o encerramento do projeto. Após a aprovação de cada projeto, haverá duas oportunidades para recebimento de inscrições de alunos. Se o número de destinatários do projeto estiver completo, o patrocinador do projeto pode clicar em "Exibir status de registro/revisão de registro" na página "Projeto atual - Meu projeto" e definir a chave "Aceitar registro" para "Não" quando a janela de informações de registro do aluno for exibida para não aceitar mais registros de alunos.

### 13. O que os alunos devem fazer caso percam a inscrição?

Durante o período de inscrição válido, caso o aluno perca esta inscrição, poderá participar da próxima inscrição.

### 14. Qual é o procedimento de arranque do projecto SRT?

Todos os projetos que receberam inscrições de alunos terão início automaticamente a partir da data de aceitação.

### 15. Qual é o procedimento de candidatura a financiamento para o programa SRT?

Ao preencher o formulário de candidatura ao programa SRT, os candidatos podem candidatar-se a fundos de projetos do programa SRT com base nas necessidades de trabalho e indicar o valor específico da candidatura (os fundos não podem ser utilizados como remuneração de estudantes). O montante do financiamento para projetos gerais não excede 5.000 yuans.

### 16. Como são aprovados e alocados os fundos para o plano SRT?

Os fundos do projeto do programa SRT são planejados e gerenciados pelo Escritório de Assuntos Acadêmicos, e os fundos do projeto são alocados em março e junho do semestre da primavera. Para projetos iniciados por alunos, os fundos do projeto serão administrados pelo instrutor. Os alunos têm o direito de controlar os fundos do projeto e o instrutor tem o direito de aprovar e supervisionar o uso dos fundos do projeto.

### 17. Qual é o procedimento de encerramento do projeto do plano SRT?

Os alunos devem enviar um relatório de conclusão completo por escrito ao instrutor e, ao mesmo tempo, preencher os resultados do projeto e a experiência do projeto on-line, e o instrutor dará notas e créditos. Projetos que atingem um determinado nível podem substituir um treinamento abrangente de teses.

### 18. O programa SRT pode substituir outros vínculos práticos relacionados ao ensino?

Se os alunos solicitarem a substituição do treinamento de tese abrangente, eles deverão se inscrever em seu departamento, preencher o "Formulário de inscrição para substituição de resultados de atividades extracurriculares do programa SRT da Universidade Tsinghua de resultados de treinamento de tese abrangente" e participar da defesa final. Os especialistas do grupo de defesa incluem membros do grupo de orientação de ensino prático da escola, membros do grupo de trabalho de orientação do plano “SRT” do departamento e instrutores. Aqueles com excelentes resultados serão aprovados.

### 19. Como a SRT planeja selecionar projetos pendentes? Há alguma recompensa?

O processo de avaliação do plano SRT é realizado em novembro do semestre de outono de cada ano letivo. Instrutores e alunos do projeto enviam inscrições e cada departamento recomenda projetos excelentes com base em uma determinada proporção do número de projetos concluídos. A escola organiza especialistas para selecionar projetos com excelentes resultados no cultivo de habilidades inovadoras dos alunos como projetos excepcionais, e recompensa seus participantes e instrutores, bem como recompensas para departamentos com excelente desempenho organizacional.
